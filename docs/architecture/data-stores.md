# Almacenamientos

## Transaccional
- **PostgreSQL LTS**: noticias, usuarios, permisos, taxonomías, flujos editoriales.

## Búsqueda
- **OpenSearch** (texto + vectorial) para indexación híbrida.

## Analítica
- **ClickHouse** para eventos, métricas y BI.

## Cache / colas
- **Redis** para cache y rate limiting.
- **Kafka/NATS** para eventos y pipelines.

## Objetos
- **S3/MinIO** para multimedia y documentos.

## Opcionales
- **Qdrant** como vector store dedicado (si se separa de OpenSearch).
