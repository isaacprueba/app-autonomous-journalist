# Servicios y límites

## API Gateway
- Autenticación, autorización, rate limiting.
- Versionado de API y routing.

## Core News
- Gestión de noticias, versiones, estados editoriales.
- Relaciones con fuentes, medios, autores, contenidos multimedia.

## Geo Taxonomy
- Estructura multinivel de regiones.
- Mapeo de localizaciones y aliases.

## Categorías y Etiquetas
- Tipos de noticias, categorías jerárquicas y hashtags.

## Usuarios y Roles
- RBAC/ABAC, grupos, permisos por módulo.
- Integración OAuth social.

## Ingesta + IA
- Crawling/scraping, normalización, deduplicación.
- Clasificación, resumen/reescritura, detección de sesgo.

## Búsqueda
- Índice híbrido, facetas, ranking, sugerencias.

## Analítica/BI
- Métricas de negocio, ratings, funnels y dashboards.

## Notificaciones
- Webhooks, correo, push, feed syndication.

## MCP/Chat
- Conectores MCP, control de permisos y trazabilidad.
