# Seguridad y cumplimiento

## Autenticación
- OAuth 2.1 con proveedores (Google, Facebook, etc.).
- MFA para usuarios administrativos.

## Autorización
- RBAC/ABAC con permisos por módulo y datos.
- Políticas multi-tenant y aislamiento por región.

## Privacidad
- Enmascaramiento y retención configurable.
- Consentimiento y auditoría de accesos.

## Moderación
- Detección de contenido sensible.
- Flujos de revisión y bloqueo.
